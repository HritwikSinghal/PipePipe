Rebasing PipePipeD from upstream v5.1.1 to **v5.2.3-beta** (client base `188c64eb9` -> `upstream/dev 85498a70d`, 169 commits drift) is a MAJOR toolchain migration, not a routine sync:

- **Toolchain jump:** Gradle 7.5 -> **9.5.1**, AGP 7.3.0 -> **9.2.1**, Kotlin 1.7.20 -> **2.3.21**, Java 11 -> **25** (source/target/jvmTarget 25, so the JDK running Gradle MUST be 25), compileSdk 33 -> **37**, minSdk 21 -> **23**, targetSdk 33 -> **36**. Root `build.gradle` is gone; plugin versions live in `settings.gradle` `pluginManagement`. Build now uses **Jetpack Compose** + the **foojay-resolver-convention** plugin.
- **Nix flake toolchain values** (validated, build green): `jdk = pkgs.temurin-bin-25`; `platformVersions = ["37"]` (resolves to `platforms/android-37.0` via androidenv's `.0` fallback); `buildToolsVersions = ["36.0.0"]` + `aapt2BuildTools = "36.0.0"` (AGP 9.2 default/min). Still NO NDK (`:ffmpeg` prebuilt aar). To stop foojay auto-provisioning a non-Nix JDK, pass `-Dorg.gradle.java.installations.auto-download=false -Dorg.gradle.java.installations.paths="${jdk.home}"` (the `-D` form; `-P` is deprecated in Gradle 9). The old `temurin-bin-11` gcc-15-miscompile rationale is now moot (still prebuilt Temurin).
- **Signing changed upstream:** upstream v5.2.x signs via env vars `KEY_PATH / KEY_STORE_PASSWORD / KEY_ALIAS / KEY_PASSWORD` (release config created only if all four are set, else silently unsigned). The fork **adopted this and dropped its `keystore.properties` block** -- CI now exports those envs from the `KEYSTORE_*` secrets (alias literal `fork`).
- **Fork build.gradle additive blocks** were rewritten for AGP 9: the old removed `applicationVariants.all { output.outputFileName = ... }` API is gone -- upstream uses `androidComponents.onVariants { output.versionCode.set() / outputFileName.set() }`. `forkAbiFilter=universal` now just sets `android.splits.abi.enable = false`; upstream's onVariants template already names the sole output `PipePipe_<ver>-universal-<type>.apk` (Obtainium filter matches), so our manual filename rewrite was deleted.
- **Extractor:** composite `includeBuild('../PipePipeExtractor')`; v5.2.3-beta pins extractor `84da35c2`. Only fork dep is the stable `YoutubeStreamLinkHandlerFactory.getId()`.
- **Rebase conflict surface:** ~44 of 59 fork files are new/no-conflict; the only HARD merge was `NavigationHelper.java` (keep upstream's `else if (loadVideo)` guard + our `previewItem` arg). `gradle.properties` -> take upstream wholesale. All DeArrow view-layer hook sites survived upstream's churn.

**Meta-repo rebase (8c) technique -- reuse for the next upstream sync:** the meta repo is *thin* (only flake, CI, README, docs, `.gitmodules`, `.gitignore`, submodule gitlinks). Upstream's v5.1.1->v5.2.3 meta diff was tiny and barely overlapped ours -- only `ci.yml` (upstream JDK 11->25) and `README.md` (a 1-line thanks credit) touched by both sides; the rest were upstream-only new files (`issue-topic-labeler.yml`, `build-ffmpeg.yml`, fastlane changelogs) or files we own outright. So instead of a literal `git rebase --onto` (which stops on ~4 conflicts, mostly throwaway gitlink/README churn from the old fix/rename commits that are now baked into the client rebase), **direct-construct** the target commits: branch off `upstream/main`, `git checkout <old-tip> -- <our files>` per logical group, do the one real 3-way merge (`ci.yml`) by hand, pin gitlinks, commit N clean commits, then `git branch -f patch <new>`. Note the extractor gitlink `84da35c2` **equals upstream's exact v5.2.3 pin**, so it's a no-op in the rebase. Verify byte-faithful with two empty-diff checks: `git diff upstream/main patch -- <upstream-only paths>` (nothing dropped) and `git diff <old-tip> patch -- <our-owned paths>` (our content unchanged). Result: 3 clean signed commits (build(nix)/ci(release)/docs). Meta force-push is agent-blocked -- the USER runs `git push --force-with-lease origin patch` (after the client is already pushed, per the client-before-meta gitlink rule).

**Operational gotchas hit this session:**
- `git` config has `commit.gpgsign=true` + `tag.gpgsign=true`: `git tag` needs `-m` (annotated); a `commit --amend` that reports "would make it empty" means the commit's content was already folded elsewhere (drop it with `git reset --soft HEAD^`). Interactive `git rebase -i` is unavailable -- reword a non-tip commit via detach + `commit --amend -F` + `cherry-pick` + `branch -f`.
- The `clean_commit_guard` hook **blocks any shell command containing the substring "claude"** -- the scratchpad path has it, so write commit-message (`-F`) files to a path without "claude" (e.g. repo root).
- Stale `local.properties` `sdk.dir` from the old toolchain (GC'd Nix store path) shadows `ANDROID_HOME` and warns "Directory does not exist"; the flake now always rewrites `sdk.dir` when it mismatches.
